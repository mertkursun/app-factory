RevenueCat's `react-native-purchases` package works in Expo managed workflow. Install with `npx expo install react-native-purchases`. Optional UI package: `react-native-purchases-ui` for pre-built paywalls.

**How to apply:** Add to Expo plugins in app.json. Requires EAS build (not Expo Go). For development testing use EAS dev-client build with sandbox environment. [[google-signin-expo]]
