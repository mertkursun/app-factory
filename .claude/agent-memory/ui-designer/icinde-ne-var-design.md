App: icinde-ne-var (ingredient scanner for Turkish market)
Design language: "Sicak, organik, sade, guvenilir" -- organic capsule/pill form language
Primary: #0F766E (teal-700 light), #2DD4BF (teal-400 dark)
Background: #FAFAF7 (warm ivory light), #0C0A09 (warm black dark)
Font: Plus Jakarta Sans (ExtraBold 800 display, Regular 400 body)
Score system: green (#16A34A) / yellow (#CA8A04) / red (#DC2626) -- traffic light metaphor
Key elements: Floating pill tab bar, pill-shaped buttons/chips, large score circle as hero, scan frame with corner brackets

**Why:** Target audience (parents, pregnant, allergy sufferers) needs trust + clarity. Teal = nature/health without conflicting with score green (33deg hue difference). Pill shapes connect metaphorically to ingredient/pharmaceutical theme while feeling friendly.

**How to apply:** If user wants changes, adjust within this direction first. Score colors are functional and non-negotiable. Primary teal must stay distinct from score green.
